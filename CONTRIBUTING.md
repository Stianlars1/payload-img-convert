# Contributing to payload-img-convert

Thanks for your interest in contributing!

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/payload-img-convert.git`
3. Install dependencies: `npm install`
4. Create a branch: `git checkout -b my-feature`

## Development

```bash
npm run build       # Build the plugin
npm run clean       # Remove dist/ and build artifacts
```

## Submitting Changes

1. Commit your changes with a clear message
2. Push to your fork
3. Open a Pull Request against `main`

## Reporting Issues

- Use [GitHub Issues](https://github.com/stianlars1/payload-img-convert/issues)
- Include Payload version, Node version, and steps to reproduce
